# han·游 Seoul Budget Trip Planner

中、韩、英三语首尔预算旅行地图。输入每日预算、旅行天数、区域和风格后，在地图上生成路线、通勤方式、餐饮推荐和菜单。

## 功能

- 首尔多区域路线，支持一日、两天一夜、三天两夜。
- 预算与路线风格筛选，显示步行、公交或地铁的预计通勤。
- 33 个餐饮/咖啡/市场地点的店铺与菜单推荐，另有 11 个热门区域备选推荐。
- 中文、한국어、English 界面；Naver 与 Google 地图搜索。
- 手机静态网页位于 `mobile_site/`，可用于 Netlify Drop 或其他静态托管。

## 运行

### 静态网页

打开 `mobile_site/index.html`。页面需要联网加载 Leaflet 地图和 OpenStreetMap 地图瓦片。

### Python 本地服务

需要 Python 3：

```bash
python korea_trip_planner.py
```

然后访问 `http://127.0.0.1:8765`。

## 发布静态网页

把 `mobile_site/` 文件夹内容上传到 Netlify Drop，或配置其他静态网站托管。部署后可通过手机浏览器访问。

## 数据说明

店铺、菜单和地点价格属于旅行参考信息，不是实时营业、库存或价格数据。出发前请确认店铺地址、营业时间及菜单。通勤方式和时长为估算，需使用地图应用核实。
